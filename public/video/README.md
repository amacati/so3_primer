# Video Files

Place your hero video files here:
- `hero.mp4` - MP4 format for broad compatibility
- `hero.webm` - WebM format for better compression

The video should be:
- High quality but optimized for web (recommend 1080p, H.264 codec for MP4)
- Loopable (seamless transition from end to beginning)
- 10-30 seconds duration
- Silent or with subtle background audio

Recommended tools for video optimization:
- FFmpeg for conversion and compression
- HandBrake for easy encoding
